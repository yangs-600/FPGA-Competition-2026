## 1. 文档范围与结论

本项目目前以 Yosys 0.69 的 `synth_intel -family cycloneiv` 为唯一正式综合入口，在该流程内部加入 PMUX 优化 pass，保持内置 ABC9 映射器不变。v15 四个公开用例 LUT 数量为 `286→221`、`25→15`、`12→12`、`35→26`，逐用例降幅的算术平均值为 **22.11038961038961%**；DFF 和其他已观察到的非 LUT 单元类型均未增加。新增窄 PMUX 夹具取得 `48→32` LUT。

已完成的代码不是从其他项目直接拼接而来。Yosys、ABC、EQY 和 SBY 构成实际工具链；`aig-opt` 只提供算法思路参考，没有复制其 LGPL 源码。其他竞赛资料仓库仅用于了解赛题背景，没有把其中代码并入本项目。

## 3. 已完成的优化内容

### 3.1 综合算法

1. **等值译码条件下的数据常量传播**：识别 `$eq`/`$logic_not` 形成的选择条件，把被选择分支中可由条件推出的信号位替换为常量。
2. **共享 Shannon DAG**：对同一控制向量驱动的 PMUX 真值表按选择位递归分解，并以 `(选择位、低分支、高分支)` 为键复用相同子树；低、高分支一致时直接折叠节点。
3. **选择位顺序搜索**：对 3–6 位控制向量枚举变量顺序，选择共享 mux 节点数最少的顺序。专用夹具选出 `order=201`，估算节点数为 `48→24`。
4. **稀疏 PMUX 默认分支补全**：v14 将“只允许缺一个编码”扩展为任意数量缺失编码；只有当所有选择信号都被证明为同一控制向量的互斥等值比较时，缺失编码才使用 PMUX 默认输入 `A`。
5. **真实成本门控**：替换收益按照原 PMUX 的显式分支数估算，不使用补全后的 `2^N` 编码数虚增原始成本；共享 DAG 节点数不优时保持原电路。
6. **安全边界**：不修改顺序单元，不处理无法证明互斥的选择器，不处理重复编码，尊重 `keep` 属性，也不依据模块名、文件名或公开测试用例进行特判。
7. **受门控的窄 PMUX 共享**：v15 支持同一 3 位译码器驱动的窄输出跨 PMUX 共享；窄组与宽组隔离，并要求至少 25% 的估算收益余量。
8. **默认数据 cofactor**：缺失编码的默认数据若直接引用控制位，则在对应编码下先替换为常量，再建立共享 DAG。

## 5. 建议实施方案

### 阶段 A：先闭合正式交付口径（P0）

1. 在独立 Windows 目录固定 Yosys 0.69 源码提交、编译器版本和所有依赖版本。
2. 分别构建原版和 v15 候选版，确认候选 pass 内置、原版拒绝该命令，并保存二进制及 DLL 哈希。
3. 对四个用例生成最终统计网表与赛题要求的 ABC 后 `$lut` ILANG。
4. 对原版/候选共 8 份输出执行正式等价验证，同时保留一个故意错误网表作为负对照。
5. 交错运行不少于 21 次，记录 CPU、墙钟时间和峰值内存；确认资源降低且运行代价满足赛题限制。

预计：**1–2 个工作日**。这一阶段不修改算法，只解决交付可信度和官方环境一致性。

### 阶段 B：建立通用回归与成本数据（P1）

1. 自动生成完整、单缺省、多缺省、重复编码、非互斥、不同数据位宽和多输出共享结构。
2. 每个候选同时记录 pass 前估算、共享 DAG 节点数、ABC9 后 LUT、CPU 和峰值内存。
3. 将“必须等价、DFF/其他单元不增加、面积不得回退”设为硬门槛。
4. 用留出用例调整成本模型，不使用公开测试模块名或路径作为特征。

预计：**1–2 个工作日**。输出应包括固定种子测试集、CSV/JSON 数据和成本门控修改建议。

### 阶段 C：再做算法扩展（P1/P2）

1. 用 sifting 或 beam search 替换大控制位宽下的全排列，同时保留 3–6 位精确搜索作为对照。
2. 分批支持掩码/部分位译码；每增加一种识别规则，都必须先定义互斥性证明和负例。
3. 引入组大小、候选节点数和搜索时间上限，超限时安全跳过。
4. 只有在隐藏结构回归中稳定获益且正式四例不退化后，才升级为下一正式版本。

预计：**2–4 个工作日**，取决于新增译码形式的复杂度。

## 6. 不建议直接采用的方案

- 不应为了通过脚本而只创建一个缺少真实哈希和工具来源的 `manifest.json`。
- 不应把不相关竞赛仓库的代码直接复制到 pass 中；必须先确认许可证、接口版本和算法适用性。
- 不应在没有互斥性证明的情况下把普通优先级 mux 当作 one-hot PMUX 重写。
- 不应直接把全排列搜索扩展到任意控制位宽，否则运行时间会按阶乘增长。
- 不应只比较 LUT，而忽略 `$not`、DFF、其他单元类型、CPU、内存和形式等价性。
