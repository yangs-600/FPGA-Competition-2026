# v13 统筹优化与 1008 答疑对齐

本轮基于 GitHub 远端 `submission/v12-official-2026-10-04` 的队友实现和本地已验证改动合并，不改变四个公开用例，也不引入按文件名、模块名或测试用例特判。

## 统筹后的算法

- 保留等值译码条件下的数据位常量传播。
- 对同一控制向量的完整 PMUX 表建立共享 Shannon DAG。
- 合并队友 v12 的 3–6 位选择器全排列搜索，确定节点数最少的变量顺序；相同节点由 `(选择位, 低分支, 高分支)` 哈希共享。
- 合并本地安全扩展：当且仅当缺少一个显式等值分支时，用 `$pmux` 默认输入 `A` 补齐该编码；缺少两个或更多编码时保持原电路不动。
- 仅在共享节点估算不高于原 AND/OR LUT 估算时提交替换，不修改顺序单元，并尊重 `keep` 属性。

独立夹具 `engineering_fixtures/selector_order_search.v` 的最优顺序为 `201`，证明选择位搜索确实生效。另有 3/4/5 位、分别缺少 0/1/2 个分支的 9 个夹具：前两类触发共享树，缺少两个分支的夹具保持不动，全部通过等价验证。

## 与 1008 答疑的对应

- 固定 Yosys 0.69，并将 pass 编译进主程序。
- 外部脚本两边都只调用 `synth_intel -family cycloneiv`；候选版在 `synth_intel` 内调用新增 pass。
- 映射器保持 Yosys 内置 ABC9，使用同一套 `&dch -f; &if -K 4 -a; &mfs` 调优脚本，不切换到传统 `abc`。
- 面积主指标仍为 `cycloneiv_lcell_comb`；同时把 `$not` 纳入逻辑计分审计，并要求 DFF 和其余每一种非 LUT 单元均不增加。
- 等价验证覆盖原版和候选版四个用例。正式交付应以 ABC 后 `$lut` ILANG 为验证对象；当前仓库保留的 Cyclone IV 逆向模型验证继续作为额外交叉检查。
- 官方运行环境为 Windows。当前 Ubuntu 虚拟机结果证明源码逻辑和 Linux 构建可复现，但不能替代最终 Windows 可执行文件及其运行库验收。
