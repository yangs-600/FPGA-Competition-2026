# Windows 原生测量口径

从新的 ASCII 路径解压后运行 run_cases.cmd。完整测量包含进程创建、读取 RTL、Yosys 综合、ABC9 等待及网表输出；同时记录根 Yosys 的 PeakWorkingSetSize。CPU/子进程 Job 数据仅补充展示，不取代墙钟或根进程峰值指标。

两个独立Yosys EXE使用同一个根目录yosys-abc.exe，由上游原有的父目录查找逻辑定位。两侧Yosys各保留本地DLL，根目录也附相同DLL供ABC使用。此布局在本轮测量前固定；原版预热自然会复用公共ABC，不额外预热候选。部署去重带来的影响与PMUX算法收益分开说明。角色目录禁止出现另一份ABC遮蔽公共文件。

每个用例先原版预热10次，测量顺序原版→候选。首轮两侧各自不足1秒、且任一相对增幅超过5%时，固定追加5对，分别取原版/候选算术平均后比较。不要求每次首轮都过线；首轮、预热和五次复核全部留存，未采用事后挑选。

FAQ C132 的“总时间不足1s”在此明确解释为单个完整综合运行。此版同时要求首轮原版和候选均不足1秒；报告另列两次总和，便于审查不同解释。5次复核不含触发的首轮，原始首轮单独报告。程序不改变系统安全设置，现场后台及安全环境仍可能影响短用例时间。

面积用每例 LUT+独立NOT 的降幅求九例算术平均，要求每例不增加，平均至少20%；DFF另列。绝对限值对保留的全部候选样本检查≤60秒和≤2,000,000,000字节。

该入口完成Windows原生综合、测量和实际post-ABC对象导出，不会冒称EQY已经运行。18项形式证明和负对照另由Linux EQY验证这些Windows生成对象，证明包通过原始报告、manifest、输入与ILANG哈希绑定。
